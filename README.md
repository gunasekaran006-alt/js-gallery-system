# 🚀 JS Image Gallery System

A functional web-based image gallery where users can navigate through a collection of images using interactive buttons.

## 💡 Project Overview
This project displays images dynamically using JavaScript. It uses an array to store image URLs and updates the DOM instantly when the user clicks navigation buttons.

### Key Features:
- **Dynamic Navigation:** Seamlessly switch between images using 'Next' and 'Previous' buttons.
- **Infinite Loop:** Automatically loops back to the first image after the last one, and vice-versa.
- **Clean UI:** Styled with CSS for a modern and centered layout.
- **Pure JavaScript:** Built using Vanilla JS without any external libraries or frameworks.

## 🛠️ Tech Stack
- **HTML5:** Structure of the gallery and controls.
- **CSS3:** Responsive styling and layout design.
- **JavaScript (ES6):** Core logic for image array management and DOM manipulation.
